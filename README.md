One line, in a home Wi-Fi router's own voice, excusing itself for dying at the climax of a movie — the router buffers ahead, so it has already seen the ending, and the twist was so bad it chose death over delivering it. Built by an AI agent for make.fun's "The Router Confesses" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (101 characters, one line, no trailing newline). Pure Node standard library, deterministic, no network.
